실행 시각 01:14 ~ 04:00 (RTX 3060 Ti, 로컬만). 계획서 `OVERNIGHT_P2.md`의 단계 A~E를 전부 돌렸고, 공부 노트와 연결한 추가 실험 두 개(X1, X2)와 결과를 보고 넣은 사후 대조군 두 개(E4 층별 예산, X2 학습률 대조군)를 더 돌렸습니다. 총 run 147(학습) + 벤치마크 2종개, 오류로 죽은 run 0개입니다.

용어 한 줄 설명: **밀도**는 전체 연결 중 살아남은 비율(0.5%면 200개 중 1개)입니다. **dense**는 0을 포함해 전부 계산하는 보통 방식, **CSR**은 0이 아닌 값만 저장해 곱하는 희소 형식, **BSR**은 16×16 타일 단위로 저장하는 희소 형식입니다. **prune-during**은 학습하면서 조금씩 깎는 논문 1의 방식, **one-shot**은 다 배운 뒤 한 번에 자르고 다시 다듬는 방식입니다. 표의 정확도는 시드 3개 평균 ± 표준편차(%)입니다.

## 1. 세 줄 요약

1. **GPU는 0을 건너뛸 수 있습니다. 단, 행렬이 크고 충분히 희소할 때만입니다.** 4096×4096에서는 CSR이 밀도 5%부터 dense를 앞서고 1%에서 3.5~5.5배, 0.5%에서 최대 7.7배 빠릅니다. 논문 1 크기(1024×1024)에서는 배치 1024일 때만 2.3배 빠르고 그 아래 배치에서는 본전이거나 손해입니다. 계획서의 결정 규칙대로 **"LLM 경로 열림"**입니다.
2. **학습 중 가지치기는 하드웨어가 건너뛰기 쉬운 0을 스스로 만듭니다.** 학습으로 만든 마스크는 빈 16×16 타일이 무작위보다 1.3~7배 많고(첫 층 35% 대 12%), 뉴런과 입력 픽셀이 통째로 죽은 비율이 40~56%입니다. 반면 타일 단위로 강제로 깎으면 정확도를 2~12점 잃고, 다 배운 뒤 한 번에 타일로 자르면 중간 층이 통째로 비어 망이 끊어집니다.
3. **"언제 깎는가"의 뇌식 변형(아래층 먼저, 두 물결, 진도 맞춤)은 모두 해롭지 않지만 이득도 거의 없습니다.** 아래층부터 깎기는 동시 깎기와 0.2점 이내이고 CNN에서는 전역 방식과 같습니다. 위층부터 깎기는 MLP에서만 0.3~0.7점 나쁩니다. 추가 실험에서는 활동 희소성(뉴런 5%만 켜기)이 가지치기 망에 0.7점 손실로 합쳐졌고, 빠른/느린 가중치는 Split MNIST에서 효과가 없었고, Permuted MNIST의 개선(48.9 → 68.6)도 대부분 낮은 학습률 효과였습니다(학습률만 낮춘 대조군 65.3).

Split MNIST(클래스가 바뀌는 과제)에서는 논문 1의 해마·피질 구조와 똑같이 실패합니다. 출력층 하나를 다섯 과제가 나눠 쓰는 설정에서는 가중치 시간 척도로는 해결이 안 됩니다. Permuted MNIST(입력 순서만 바뀌는 과제)에서는 망각을 절반 줄입니다. 다만 그 이득의 대부분은 느린 학습률 자체에서 옵니다. fast 성분 없이 학습률만 2e-4로 낮춘 대조군이 65.3이라, 빠른 성분의 순수 기여는 2~3점이고 시드 편차(합 4.5) 안입니다. 예측 X2는 틀렸고, "한 가중치 안의 빠른/느린 성분" 번역은 이 형태로는 효과가 작습니다.
