## P4-A 같은 메모리 상한 (Split CIFAR-10 온라인 클래스 증분, CNN16, 장부 256KB·1MB·4MB)

- **A1**: 4MB 에서 최선 역전파(bp·bp_mem 중 높은 쪽)는 최선 역전파 없는 학습기(np_layer·fg 중 높은 쪽)보다 A_AUC 가 5 점 이상 높다.
- **A2 (결정)**: 256KB 에서 역전파 없는 학습기 중 하나가 아낀 바이트를 재현 버퍼에 써서 최선 메모리 절약 역전파(bp_mem)보다 A_AUC 가 2 점 이상,
  확실히 높다. **틀리면 "메모리 상한에서는 싼 학습기가 이긴다"는 주장을 이 규모에서는 폐기한다.**
- **A3**: 업데이트당 순전파 등가 수(연산 축)로 다시 채점하면 모든 상한에서 역전파가 이긴다.
- **A4 (해석적 음성 대조)**: MNIST MLP 784-1024-1024-10 에서 역전파 장부 중 활성값 몫은 배치 20 에서 10% 미만이다 → 메모리 이점이 원리적으로 없다.
- **A5 (희소성)**: 256KB 에서는 밀집망(매개변수만 553KB)이 아예 들어가지 않는다. 희소 10% 망만 경기에 남는다.

## P4-B 노드 섭동 안정성 대조 (MNIST MLP 1024-1024, 처음부터 15 에폭, v3 프로토콜)

- **B1**: 밀집망 노드 섭동은 입력 수 비례 학습률(층마다 lr / 입력 수 비율) 또는 행별 가중치 정규화를 주면 발산하지 않고 85% 이상 간다.
  맞으면 p3 의 "희소성이 노드 섭동을 안정시킨다"는 학습률 규모 효과로 다시 쓴다(Hiratani 2022). 틀리면(그래도 발산) 희소성 효과로 남긴다.

## 수정 (2026-10-08 02:52, 실험 실행 전 — 해석 장부를 계산해 본 뒤)

장부(experiments/p4/iso_memory.py, 이상적 구현 해석식)를 계산하니 256KB 에서는 어떤 학습기도 CNN16 희소 10% 를 돌릴 수 없다
(첫 블록 32x32x16 특징 지도가 표본당 작업 메모리 약 200~300KB 를 차지 — 역전파·노드 섭동·순방향 기울기 모두). 그래서:
- 상한을 384KB / 512KB / 1MB / 4MB 로 바꾼다. A2 는 "역전파가 아닌 학습기와 메모리 절약 역전파가 둘 다 들어가는 가장 작은 상한"(384KB) 에서 판정.
- 배치 정책: 재현 버퍼 최대(스트림 1 장 + 재현 1 장, 나머지 바이트 전부 버퍼) — "아낀 바이트를 재현에" 경로를 가장 유리하게.
  장부상 버퍼(희소 10%): 384KB 는 bp_mem·np 모두 재현 없음(bp·fg 는 안 들어감), 512KB np 8 장(나머지 0), 1MB bp 100 / bp_mem 147 / np 179 / fg 106,
  4MB bp 1123 / bp_mem 1170 / np 1203 / fg 1129. 즉 이 망에서는 아낀 바이트가 재현 버퍼를 최대 수십 % 밖에 늘리지 못한다.
- 밀집망(매개변수 540KB)은 1MB 에서 np 만, 4MB 에서 모두 들어간다.
- bp_mem 은 bp 와 같은 기울기·같은 갱신이므로 학습률을 공유한다(메모리만 다름).
- 예측 A1~A5 는 그대로 둔다. 추가 예측 **A6**: 384KB(둘 다 재현 없음)에서 bp_mem 이 np 보다 A_AUC 10 점 이상 높다.
