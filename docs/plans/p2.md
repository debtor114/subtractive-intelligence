# 논문 2 탐색 실험 (experiments/p2) — 선행연구 사후 기록

작성 2026-10-06. 실험은 OVERNIGHT_P2.md 계획으로 10-06 새벽에 먼저 돌렸고(결과 results/p2/REPORT_MORNING.md,
예측 등록 results/p2/PREDICTIONS.md), 선행연구는 실험이 끝난 뒤에 확인했다. 이 문서는 그 순서가 틀렸다는
기록(ADR-006)이자, p2 실험을 다시 돌릴 때 훅 check_prior_art.py 가 보는 관문이다.

표의 선행연구 판정은 사용자가 2026-10-06 아침 외부 검토로 받아 붙인 것이다. 이 세션에서 원문을 다시 열어
확인하지는 않았다(후속 후보의 선행연구는 docs/plans/p3_candidates.md 에서 논문마다 검증한다).

| 실험 | 관련 선행연구와 우리 차이 | 판정 |
|---|---|---|
| E1 희소 계산 속도 측정 (e1_micro.py, e1_real.py) | SparseRT, Sputnik (Gale 등 2020), Flash-LLM (2023) 등이 밀도별로 희소 커널 속도를 쟀다. 측정 방법 자체는 새롭지 않다. 우리 차이: 논문 1 크기의 층과 4096² 행렬을 같은 소비자 GPU(3060 Ti)에서 CSR/BSR/2:4로 재어 "우리 학습 마스크가 공짜가 되는 밀도"를 특정한 것뿐이다. | 있음 (측정법 기존) |
| E2 아래층부터 깎기 (run_stage.py e2) | 두 번 검색했지만 층마다 깎는 시기 순서(bottom_up/sync/top_down)를 같은 최종 밀도에서 비교한 연구는 못 찾았다(2026-10-06). 우리 차이: 가장 새롭지만 결과는 중립(정확도 차이 0.3 이내, top_down 은 비용만 2배). | 못 찾음, 결과 중립 |
| E3 두 물결·진도 맞춤 (run_stage.py e3) | 여러 번 나눠 깎기는 반복 가지치기(Han 등 2015, Lottery Ticket 2019)와 Cyclical Pruning (2022)이 이미 했고, 학습이 안정된 뒤 깎기 시작하는 것은 Early-Bird Tickets (2020)이 했다. 우리 차이: 없다. 두 물결·진도 맞춤 모두 sync 와 0.3 이내. | 있음 |
| E4 블록 모양 학습 중 깎기 (run_stage.py e4, e4pl) | Block-Sparse RNN (Narang 등 2017)이 학습 중 블록 단위 점진 가지치기를 이미 했다. 한 번에 자를 때 층이 통째로 비는 현상은 SynFlow (Tanaka 등 2020)의 layer collapse 다. 우리 차이: 층별 타일 예산으로 one-shot 을 살려도 prune-during 보다 손실이 큰 것(10~36점)을 극단 밀도(0.5~3%)에서 보인 정도. | 있음 |
| 타일 점유율·죽은 뉴런 (e1_real.py) | 같은 측정(학습 마스크의 빈 16×16 타일 비율 대 무작위 마스크)은 이번 검색에서 따로 확인하지 못했다(2026-10-06). 비구조적 가지치기가 뉴런·채널을 통째로 죽인다는 관찰 자체는 흔하므로 확인이 더 필요하다. | 확인 필요 |
| X1 뉴런 5%만 켜기 + 희소 연결 (run_stage.py x1) | How Can We Be So Dense? (Ahmad & Scheinkman, Numenta 2019)가 희소 가중치와 k-WTA 활성화를 MNIST 에서 함께 썼다. 우리 차이: 연결 희소성을 학습 중 가지치기로 만든 것과 "같은 예산의 작은 dense 망은 무너진다"는 대조뿐. 거의 같은 실험이 있다. | 거의 같은 실험 있음 |
| X2 빠른/느린 가중치 (x2_fastslow.py) | Hinton & Plaut (1987)의 fast weights, 논문 1에 인용한 CLS-ER (2022, 빠른/느린 두 모델). 우리 차이: 한 가중치 안의 두 성분이라는 구현뿐이고 결과는 효과 없음(Split 무효, Permuted 는 학습률 대조군 안). | 있음, 우리 결과 효과 없음 |

교훈: 7건 중 5건이 알려진 결과였고 가장 새로운 1건은 중립이었다. 하룻밤 GPU 의 대부분이 재확인에 쓰였다.
