# ADR-003: 핵심 실험 설계 - 학습 중 가지치기 대 가산 / 학습 후 가지치기 / 동적 희소

- 상태: 확정, 1 차 실행 (2026-10-01 밤)
- 코드: experiments/core_prune_during_learning/, core/masked_layers.py, core/pruning.py

## 질문

같은 최종 연결 예산에서, "과잉 초기화 후 학습 중에 깎는" 감산 방식이 (a) 처음부터 작은 dense 망(가산),
(b) 다 배운 뒤 한 번에 깎는 방식(LTH 류), (c) 처음부터 희소하게 시작해 끊고 잇는 동적 희소 학습(SET/RigL)
과 비교해 정확도 / 데이터 효율 / 확신도 보정 / 누적 학습 연산량에서 어디에 서는가.
그리고 "무엇을 깎을지" 를 gradient 나 크기가 아닌 지역 활동 규칙(STDP 형)으로 정해도 되는가.

## 설정

- MNIST, MLP 784-h-h-10. 과잉 망 h=1024 (1,861,632 가중치). Adam lr 1e-3, cosine, 배치 128, 15 에폭 (9,380 스텝).
- 예산 = 밀도 d x 1,861,632, d in {0.1, 0.05, 0.02, 0.01, 0.005}. dense small 은 784h+h^2+10h = 예산인 h.
- 감산 스케줄: cubic (Zhu & Gupta 2017), 밀도 1 -> d 를 전체 스텝의 10% ~ 70% 구간에서 100 스텝마다. 재성장 없음.
- 규칙: magnitude(층별/전역), activity(헤비안 상관 |E[relu(y_i) x_j]|), |w| x activity, random(대조),
  drive(|w_ij| x E[1(y_i>0)|x_j|], 후뉴런 발화 시 그 시냅스로 흐른 입력량. 2 차 추가).
- 학습 후 가지치기(ttp): dense 로 15 에폭 -> 전역 크기 가지치기 -> 7.5 에폭 미세조정.
- SET / RigL: 밀도 d 무작위 마스크로 시작, 100 스텝마다 살아있는 연결의 0.3 x cos 감쇠 비율을 끊고
  같은 수를 무작위(SET) / dense gradient 크기(RigL) 로 다시 잇기. 75% 지점까지.
- static sparse: 밀도 d 무작위 고정 마스크.
- 지표: 최종/최고 정확도, 학습곡선(100 스텝마다 전체 테스트), 누적 학습 FLOPs (매 스텝 실제 활성 연결 x 배치 x 2 x 3),
  추론 FLOPs (2 x 활성 연결), ECE/NLL/AUROC/AURC, 97%/98% 도달 표본 수, 가지치기 궤적.
- 시드 3.

## 예상되는 반론과 대응

- "과잉 망을 깎으면 작은 dense 망보다 낫다는 건 이미 알려졌다" (Zhu & Gupta 2017, Frankle 2019).
  -> 맞다. 이 실험의 기여는 (1) 같은 표에 누적 학습 비용을 넣어 그 이득의 값을 보여주는 것,
     (2) gradient 없는 지역 규칙이 크기 규칙을 대체할 수 있는지 검증하는 것, (3) 데이터 효율과 보정까지 같이 보는 것.
- "MNIST MLP 는 너무 쉽다" -> 맞다. 1 차는 파이프라인 검증. CIFAR-10 소형 CNN/ViT 로 확장 예정.

## 1 차 결과 요약 (d=0.1, 시드 3, 2026-10-01 01:40 시점)

| 방식 | 정확도 | 누적 학습 FLOPs |
|---|---|---|
| dense big (예산 무시) | 98.71 | 1.0e13 |
| dense small (가산) | 98.36 | 1.0e12 |
| 학습 중 가지치기, 크기 | 98.67 | 3.3e12 |
| 학습 중 가지치기, 활동(헤비안) | 98.19 | 3.3e12 |
| 학습 중 가지치기, |w| x 활동 | 98.57 | 3.3e12 |
| 학습 중 가지치기, 무작위 | 98.23 | 3.3e12 |
| 학습 후 가지치기 + 미세조정 | 98.68 | 1.06e13 |
| RigL | 98.53 | 1.0e12 |
| SET | 98.38 | 1.0e12 |
| static sparse | 98.18 | 1.0e12 |

- 학습 중 크기 가지치기는 10% 연결로 과잉 망과 같고 (98.67 vs 98.71), 가산 dense small 보다 +0.3%p.
  비용은 dense small 의 3.3 배, 학습 후 가지치기의 1/3.
- 순수 헤비안 상관은 무작위와 같다. E[y_i x_j] 는 시냅스 ij 의 기여가 아니라 다른 경로를 통한 상관까지 섞기 때문.
  -> drive 규칙 추가 (시냅스별 기여만 본다).
- RigL 은 학습 비용 1/3 로 98.53. 효율 프런티어에서는 RigL 이 강하다. 정직하게 보고.

관찰
1. 학습 중 전역 크기 가지치기가 모든 밀도에서 1 위. 희소할수록 격차가 커진다 (0.5% 에서 dense small 대비 +3.7%p,
   학습 후 가지치기 대비 +3.3%p, RigL 대비 +1.5%p). 학습 후 한 번에 깎는 방식은 0.5% 에서 무너진다 (94.5).
   -> "깎는 것 자체" 가 아니라 "배우면서 점진적으로 깎는 것" 이 핵심. 논문 주장의 직접 근거.
2. 헤비안 상관 규칙은 무작위와 dense small 사이. 시냅스별 기여를 못 잡는다. abs(w) x 활동은 크기 단독보다 못하다.
   -> 지역 규칙만으로는 크기 규칙을 못 이긴다 (이 설정에서). drive 규칙 결과는 추가 스윕 후 기록.
3. 데이터 효율: 과잉 망은 97% 도달에 87k 표본 (dense small 133k~436k, RigL 124k~445k). 표본당 비용은 크지만
   표본 수로는 가장 빨리 배운다. 누적 FLOPs 는 dense small 의 3~50 배 (밀도가 낮을수록 배율이 커짐).
4. 보정 (ECE) 은 모든 방식 0.004~0.015 로 차이가 작다. 무작위 가지치기만 0.015 로 나쁘다.
5. 효율 프런티어 (누적 학습 FLOPs 기준) 에서는 RigL 이 가장 싸고 정확도 2 위. 논문에서는 "정확도 대 최종 연결" 과
   "정확도 대 학습 비용" 두 축을 모두 제시해야 정직하다.

- 지역 규칙 순위: drive > abs(w) x 활동 > 활동. 시냅스 단위 기여를 볼수록 좋다.
- drive 는 크기에 못 미치지만 dense small / 학습 후 가지치기 / SET 보다 높고 RigL 에 근접. gradient 없는 지역 규칙으로
  "학습 중 점진 가지치기" 이득의 대부분을 얻는다.
- 다음 후보: drive 에 시간 창(최근 활동 가중) 추가, 층별 밀도 배분을 전역처럼 자유롭게 (전역 크기가 층별보다 좋은 이유).

## CIFAR-10 확장 (2026-10-01 오전, experiments/core_prune_during_learning/run_cifar.py)

- 모델: VGG 풍 소형 CNN (conv 64-64 / 128-128 / 256-256, fc 256, BatchNorm), 프루닝 가능 가중치 2,195,648.
  dense small 은 같은 구조에서 채널을 width 배율로 줄여 가중치 수를 예산에 맞춤 (width = sqrt(밀도) 근처).
- 학습: SGD nesterov lr 0.05 cosine (1 에폭 warmup), wd 5e-4 (BN/bias 제외), 배치 128, AMP, 20 에폭. ttp 는 +10 에폭 미세조정 lr 0.01.
- 데이터: GPU 상주 uint8 + GPU 증강 (패딩 4 랜덤 크롭, 반전). DataLoader 워커 0 (커밋 메모리).
- 밀도 0.1 / 0.03 / 0.01 (가중치 22 만 / 6.6 만 / 2.2 만), 시드 3. 방식: dense_small, pd_mag_global, pd_mag_erk, pd_drivenorm_erk, rigl (ERK 초기 밀도), ttp, dense_big.
- 2 에폭 연기 테스트에서 드러난 것:
  1. 균일 층별 밀도는 첫 conv (1,728 가중치) 를 굶겨 붕괴 -> 층별 규칙은 ERK 배분으로 목표를 준다 (scope="erk").
  2. 시냅스 구동 규칙 원형은 CNN 에서 붕괴 (정확도 10%). 발화가 적은 채널의 입력이 통째로 잘려 채널이 죽고 하류로 번짐
     (항상성 없는 활동 의존 가지치기의 알려진 위험). -> 후뉴런별 구동 평균으로 정규화한 drive_norm 을 본 스윕에 사용.
  3. 임계값 비교 (score >= thresh) 는 동점(점수 0) 이 많으면 연결 수가 부풀어 (90k vs 66k) -> 정확한 top-k 인덱스 선택으로 교체.
  4. CNN 에서는 같은 가중치 수라도 conv 를 남기면 추론 FLOPs 가 훨씬 크다 (ttp 4.6e7 vs dense small 9.7e6).
     정확도 대 추론 FLOPs 그림을 추가. 논문에는 두 축 모두 제시.
- 실행 시간: 런당 7~12 분, 전체 약 7 시간. 결과는 results/core_cifar/, 집계는 scripts/analyze.py core_cifar.
