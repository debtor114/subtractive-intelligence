# ADR-005: 실험 5 - 추론 중 가지치기 (입력 의존적 동적 희소화) 최소 실험

날짜: 2026-10-01 밤. 상태: 팟 대기열 (runpod/queue_exp5.sh, 앞 작업 종료 후 자동 시작).

## 배경

사용자 로드맵 (docs/notes/roadmap_candidates_1001.md) 후보 1: "학습 중 가지치기가 최고라면, 그 가지치기를 추론 중에도 하면?"
입력마다 다른 서브망을 쓰는 동적 신경망 문헌은 이미 있다 (채널 게이팅, Deja Vu 의 문맥 희소성 등). 비어 있는 질문은
**연결 단위 + 국소 규칙 + 학습 중 가지치기와 같은 일정 + 정적 희소망과 동일 FLOPs 비교** 다. 토큰 스킵 실험 (exp12) 에서
"어느 토큰을 고를지는 무작위와 동률" 이었으므로, 연결 단위에서도 선택 기준이 무의미한지가 핵심 질문이다.

## 결정

1. **팔 셋 + 정적 대조군 재사용.** dyn_local (연결 단위, 국소 규칙), dyn_random (연결 단위, 무작위 - 선택 기준 대조군),
   kwta_in (채널 단위 k-WTA 입력 게이팅 - GPU 에서 실제 속도가 나는 유일한 형태). 정적 대조군 (학습 중 전역 크기, ERK, dense small,
   RigL, 학습 후 가지치기) 은 results/core_resnet 의 같은 밀도 결과를 그대로 쓴다. 밀도 0.2 만 새로 돈다 (pd_mag_global, dense_small).
2. **국소 점수 = |w[o,j]| x a[b,c(j)]**, a 는 입력 채널의 공간 평균 |x|. 출력 뉴런별 상위 k. 이것은 논문 1 의 시냅스 구동 규칙에서
   "후뉴런 발화" 항을 뺀 표본별 판이다 (후뉴런 출력은 마스크를 정하기 전엔 모른다). 점수는 detach, 마스크는 하드 0/1.
3. **표본별 가중치는 unfold + bmm.** Wm[b] = W * M[b] 를 (B, C_out, J) 로 만들고 im2col 한 입력과 bmm. 메모리 B x params
   (B=128 이면 fp16 으로 약 6GB + 저장분). groups=B 의 grouped conv 보다 예측 가능해서 택했다. 첫 conv (J=27) 와 fc 는 밀집 유지.
4. **밀도 스케줄은 논문 1 과 동일** (cubic, 학습의 10%~70%, 100 스텝마다). 밀도 1.0 구간은 dense 경로라 빠르다.
5. **평가 비용 절감.** 연결 단위 경로는 평가도 느리므로 (표본별 가중치) 학습 중 평가는 테스트 앞 2000 장 / 200 스텝마다, 최종만 1 만 장.
   평가 배치는 250 (1000 이면 층 하나가 4.7GB - 로컬 8GB 에서 OOM 으로 확인).
6. **마스크 통계.** 클래스별 20 장 (200 장) 으로 1/3/4 단계 블록 둘째 conv 의 표본별 마스크를 잡아 같은 클래스 쌍 / 다른 클래스 쌍
   자카드 유사도와 합집합 커버리지를 기록. J_same >> J_diff 면 "고양이 서브망 vs 자동차 서브망" 이 실재. 무작위면 둘 다 약 밀도.
   교집합은 fp32 조각 누적 (fp16 내적은 65504 를 넘어 inf - 연기 테스트에서 발견).
7. **판정 기준.** (a) dyn_local 이 dyn_random 을 못 이기면 "선택 기준 무의미" 가 연결 단위로 확장된 것 (그것도 결과).
   (b) dyn_local 이 같은 FLOPs 의 정적 학습 중 가지치기를 이기면 동적 용량 (union coverage 가 밀도보다 훨씬 큼) 이 이득의 출처.
   (c) kwta_in 은 극단 희소 (0.5%) 에서 무너질 것으로 예상 - 채널 단위는 어디까지 내려가는지가 기록.

## 비용

팟 (다른 5 갈래와 공유 중) 측정: dyn_local B=128 스텝 약 0.3 s, 최종 평가 + 통계 약 55 s. 런당 약 30~45 분 추정, kwta_in 은 10 분.
스윕 = 밀도 {0.05, 0.005, 0.2} x 팔 3 x 시드 2 = 18 런 + 정적 0.2 x 2 팔 x 2 시드 = 22 런, 시드별 2 갈래 병렬로 약 4~5 시간.

## 알려진 한계

- 연결 단위 동적 마스크의 FLOPs 절감은 이론값이다. 밀집 GPU 커널은 그대로 돈다 (논문 1 의 연산-기억 통합 논지가 여기도 적용).
- 첫 conv 와 fc 를 밀집으로 두므로 정적 팔 (전부 가지치기) 과 FLOPs 가 약 0.3% 다르다. 표에 적는다.
- 점수에 후뉴런 정보가 없다. "post fires" 를 넣으려면 두 번 계산해야 해서 (compute-all-then-select) 제외했다.

## 수정 이력 (2026-10-01 21:00~21:50, 팟 실행 중 발견)

- **메모리 26GB/프로세스 -> 2.7GB.** 원인 둘. (1) 표본별 가중치 Wm 과 마스크 M 이 층마다 역전파용으로 저장됨 -> 연결 단위 경로를
  비재진입 체크포인트로 감싸 역전파 때 재계산. (2) topk 가 k 개의 int64 인덱스 (B x C_out x k x 8 바이트) 를 만들어 밀도 1 근처인 스케줄
  초반에 층 하나가 2~5GB (평가 배치 250 에서 4.35GiB 할당 실패) -> kthvalue 로 뉴런별 k 번째 점수만 구해 임계값 비교로 마스크 생성.
  점수는 fp32 (fp16 은 동점이 많아 마스크 개수가 틀어짐). 점수 0 인 연결 (죽은 입력 채널) 은 뽑지 않는다.
- **dyn_random 은 뉴런별 정확히 k 개가 아니라 같은 기대값의 베르누이 마스크** (topk 없이 싸다). 기대 활성 비율은 같다.
- **속도.** kthvalue 가 가장 비싼 연산이라 체크포인트 밖에서 한 번만 구하고 (B, C_out, 1) 임계값만 안으로 넘긴다. 팟 (5~6 프로세스 공유)
  측정 dyn_local 1.2 s/스텝, dyn_random 0.4~0.7 s, 평가 B=125 전진 0.7 s. 단독이면 약 0.3~0.4 s/스텝 추정 -> 런당 40~60 분.
- 평가 배치 125, 학습 중 평가는 2000 장 / 200 스텝. 실행 순서는 결정적 비교가 먼저 나오게 d=0.05 (시드 0, 1) -> 0.005 -> 0.2,
  팔별 갈래 (runpod/start_exp5_dyn.sh 두 갈래 + start_exp5_now.sh 의 light 갈래 = kwta_in 전부 -> 정적 0.2).
- 함정: ssh 원격 pkill -f 패턴에 같은 명령줄의 다른 부분 (예: 재시작 명령의 스크립트 이름) 이 매칭되면 ssh 세션 자체가 죽는다 (255).
  kill 과 relaunch 는 별도 ssh 호출로.
