# ADR-004: 보조 실험 1~4 의 재정의와 구현 결정

- 상태: 확정, 1 차 실행 (2026-10-01 밤)

## 실험 1: 억제 기반 희소 어텐션 -> 사전 라우팅 (core/thalamic_router.py)

- 원안(사후 top-k 마스킹) 은 QK^T 를 다 계산한 뒤 지우므로 이론 FLOPs 가 줄지 않는다. 대조군으로만 둔다.
- 사전 라우팅: 헤드별 저차원 투영(D=32 -> r=8) 으로 라우팅 점수를 만들고 쿼리마다 상위 k 키만 골라
  전차원 어텐션을 그 k 개에 대해서만 계산. 라우터는 학습 중에만 계산하는 전체 어텐션 분포를 교사로 KL 학습.
- 정직한 계산: 토큰 50~65 개 ViT 에서 어텐션 행렬곱은 블록 FLOPs 의 5% 안팎. 어텐션 FLOPs 와 총 FLOPs 를
  따로 보고한다. 원안의 "FLOPs 50% 감소" 는 어텐션만 희소화해서는 이 규모에서 불가능하다.
- MNIST ViT (patch 4, dim 128, depth 4, heads 4, 8 에폭, 시드 3) + CIFAR-10 ViT (dim 192, depth 6, 30 에폭, 시드 1).

## 실험 2: 예측 코딩 -> 층간 예측 오차 기반 토큰 스킵 (core/predictive_coding.py)

- 정적 이미지에는 시간축이 없으므로 "층 i 가 토큰을 얼마나 바꿀지" 를 저랭크 예측기(r=16) 로 미리 추정하고
  변화가 작다고 예측된 토큰은 그 블록을 건너뛴다 (identity 또는 예측 잔차로 대체). CLS 는 항상 계산.
- 학습된 ViT 위에서 사후 적용 (예측기만 MSE 로 3 에폭). 점수: predicted(제안) / random(대조) / oracle(상한).
- FLOPs 는 해석적: k/v 투영은 전 토큰, q 투영 + 어텐션 행 + proj + MLP 는 계산된 토큰만. 예측기 비용 포함.
- 스킵된 토큰도 키/값으로는 남는다 (A-ViT 방식).

## 실험 3: 이중 학습률 + 수면 (experiments/exp3_dual_learning/)

- Split MNIST Class-IL (5 태스크, 단일 헤드), Permuted MNIST (10 태스크). MLP 784-256-256-10. 태스크당 3 에폭.
- fast(해마): Adam lr 3e-3, 스트림만 학습. slow(피질): 수면에서만 학습 (현재 태스크 데이터 + 버퍼 500 리플레이,
  CE + fast 로부터 KD T=2). 수면 시작 때 전역 감쇠, 수면 끝에 약한 연결 가지치기 (마스크, 영구).
- 대조군: fine-tune, ER (버퍼 500), ER 2 배 에폭 (연산량 근사 대응), joint (상한).
- "모르겠다" 측정: 각 시점에서 아직 안 배운 클래스를 확신도(softmax max / 엔트로피 / fast-slow 합의도) 로
  가려내는 AUROC.
- 결과 (Split, 시드 3): ER 85.2 / CLS+수면(증류) 78.7 / CLS+수면(증류 없음) 85.0 / 감쇠 77.4 / 가지치기 79.2.
  해마->피질 증류는 현재 태스크 편향을 옮겨 망각을 키운다. 수면 단계의 감쇠/가지치기는 이득이 없다.
  fast-slow 합의도는 미지 클래스 탐지에 무용 (AUROC 0.51). 원안 가설은 이 구현으로는 기각.
- 메모리 함정: joint 가 태스크 데이터를 전부 GPU 에 쌓아 (Permuted 10 x 188MB) WDDM 커밋 메모리를 10GB 까지
  먹었다. 태스크당 20k 표본 fp16 으로 제한 + 실행 사이 empty_cache.

## 실험 4: STDP (experiments/exp4_stdp_temporal/)

- Diehl & Cook 2015 구조를 순수 PyTorch 로 GPU 벡터화 (BindsNET v2 단순화: 흥분층 내 재귀 억제 17.5,
  적응 임계 0.05, 흔적 STDP nu=(1e-4, 1e-2), 열 정규화 78.4, 포아송 128 Hz, 250 ms, dt 1 ms). 배치 32.
- brian2 는 Windows 에서 빌드 실패 (C 컴파일러). norse 는 설치됐지만 STDP 비지도 학습에 맞지 않아 미사용.
- 이론 연산량은 사건 구동 SOP 로 센다 (입력 스파이크 x n_e + 흥분 스파이크 x n_e + 스텝 x n_e). 에너지 실측 없음.
- 대조: 같은 폭 MLP 784-n_e-10 을 같은 표본 수만 역전파 (Adam, bs 32). 데이터 효율(80% 도달 표본 수) 비교.
- 가지치기 궤적: 학습 중 가중치 분포 (1% 이하 비율, Gini) 를 5,000 장마다 기록.

## 실험 3 재설계 (2026-10-01 오후, 사용자 설계)

변경: fast(해마) 에 k-WTA (활성 5~10%) 로 패턴 분리 강제, 증류 제거, 리플레이 배치를 본 (태스크, 클래스) 그룹이
같은 수가 되게 구성, 수면 가지치기는 크기 기준만 (전역 감쇠·활동 기준 제거). 대조군으로 온라인 ER 의 균형 판 추가.
예측은 slow 기본, 대안으로 fast 단독과 fast/slow 중 확신도 높은 쪽 (R_alt).

Split MNIST (Class-IL, 시드 3) 결과:
- ER 균형 배치 87.8 (기존 ER 85.2, +2.6%p). CLS2 (균형 수면 리플레이) 87.0. fast 단독 19.7 (k-WTA 유무 무관).
  fast/slow 확신도 선택 66~68 (해로움). 크기 가지치기 5%/수면 중립 (86.9).
- 증류를 뺀 순간 slow 는 fast 와 완전히 분리되므로 fast 의 희소성은 slow 결과에 영향이 없다 (dense/10%/5% 가 같은 시드에서
  동일한 slow 결과). 희소 해마가 피질에 기여하려면 어떤 형태로든 전달 경로(증류, 특징 공유)가 필요하다 - 그런데 증류는 편향을 옮긴다.
- 은닉층 k-WTA 는 공유 출력층의 간섭을 막지 못한다. Class-IL 에서 fast 는 여전히 완전 망각.
- 결론: 재설계의 이득은 전부 "균형 리플레이" 에서 나온다. 알려진 기법 (class-balanced replay) 의 재확인.

함정: 균형을 클래스만으로 잡으면 Permuted MNIST (모든 태스크에 10 클래스) 에서 버퍼가 전혀 쓰이지 않아 fine-tune 과 같아진다
(52%). (태스크, 클래스) 그룹 기준으로 수정 -> 87.9 (seed 0). 그룹 인덱스를 매 스텝 재계산하면 느려 (275 s/런) 캐시 도입.

## 실험 1+2 통합: 사전 필터링 (2026-10-01 오후, core/thalamic_skip.py, experiments/exp12_prefilter/)

설계: 앞쪽 절반 블록 전부 계산 -> 경계에서 시상 라우터(MLP dim->64->n_late) 가 토큰별 뒤쪽 블록별 예상 변화량(log1p 잔차 노름)
을 한 번에 예측 -> 뒤쪽 블록 i 는 상위 (1-s) 토큰만 계산, 나머지는 x + predictor_i(x). 구현은 전 토큰 계산 뒤 대체 (값은 부분 계산과
동일, 미분 가능, 어텐션 변형과 조합 가능). 워밍업 1 에폭 (ViT 고정) -> 스킵 0 -> 0.7 점진 미세조정. 선택 기준 thalamic / layerwise /
random 교차 평가. 뒤쪽 어텐션 사전 라우팅(키 25%) 변형.

결과: MNIST 3 시드 워밍업만 70% 스킵 98.10 (원본 98.27, FLOPs 0.73); 미세조정은 -0.2%p (포화). CIFAR 1 시드 미세조정 후 70% 스킵 80.8
(원본 81.8, FLOPs 0.72), 50% 81.1. 선택 기준 3 종은 두 데이터 모두 오차 범위 (교차 평가도 동일). 사전 라우팅 어텐션은 FLOPs -1%p 에 -0.1~0.6%p.
결론: 이득 = '뒤쪽 블록만 + 예측 잔차 대체'. 어느 토큰을 고를지는 무관 -> 시상은 선택 장치가 아니라 층별 예산 사전 결정 장치로만 의미.
논문: 실험 1, 2 를 "사전 필터링" 한 절로 묶고 선택 규칙·어텐션 라우팅은 부정적 결과로.
